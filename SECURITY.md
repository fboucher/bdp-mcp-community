# Security policy

## Reporting a vulnerability

Do not disclose vulnerabilities, credentials, or sensitive customer information in public issues, discussions, or pull requests.

Use GitHub's private vulnerability reporting: open the repository's **Security** tab, choose **Advisories**, and select **Report a vulnerability**. Include affected versions, a description of the impact, and reproduction steps using fictional data. Do not include live credentials or customer data.

Private vulnerability reporting is not yet enabled for this repository. A repository administrator must enable it before the reporting option is available. Until then, contact a repository maintainer privately through an existing trusted channel; do not post the report publicly.
